# SwitchRPCEnhanced

### An enhanced Nintendo Switch/Switch 2 Discord integration available for Linux, macOS, and Windows, now with an updated game list.

The list now comes with 500 game titles built-in, you can also add your own titles under *Custom Games*, as well as, local boxart to them in the menu via the *Game Box Art Manager*.
All games have a fallback image of the console they are played on, this will show in the Rich Presence on Discord since it's currently linked to mine... 

You can change the *Application ID* in the *"[index.js](https://github.com/leonhartm47/SwitchRPCEnhanced/blob/master/index.js)"* file and create your own on the *[Discord Developer Portal](https://discord.com/developers/home)* which allows you to upload the *"[Discord Assets](https://github.com/leonhartm47/SwitchRPCEnhanced/tree/master/assets/Discord%20Assests)"* folder included to display the images I've used for the consoles as a fallback or you can create your own and replace over them etc.  *"[Game Box Arts](https://github.com/leonhartm47/SwitchRPCEnhanced/tree/master/assets/Game%20Box%20Arts)"* can be added locally and the name for the image is generated by the title used, there's protections in place to prevent duplicates for both the title or aliases used.  I've only uploaded a few images of games so far, but you can use the maximum number of 300 images in total by *creating your own application* as mentioned earlier in the [Discord Developer Portal](https://discord.com/developers/home).  It should be straightforward to understand how to use it, there are various features which I felt were needed as I was tweaking/using it and came across issues which prompted improvements towards enjoying the experience of using it.

The game library is handled by the *"[rpc.json](https://github.com/leonhartm47/SwitchRPCEnhanced/blob/master/resources/rpc.json)"* database file directly, this also includes a section for *recommended descriptions* linked to some of the franchises of the games added etc. these are shown when you select the game or you can override it and type your own.  I've also added a *Refresh library* button to just create a quick way of updating new entries added to the database if someone were to manually add something to the *"[rpc.json](https://github.com/leonhartm47/SwitchRPCEnhanced/blob/master/resources/rpc.json)"* directly, as well as, the box-art images if any have been added manually to the *"[Game Box Art](https://github.com/leonhartm47/SwitchRPCEnhanced/tree/master/assets/Game%20Box%20Arts)"* directory directly.  This generally isn't needed unless you're adding manually, you can use the onboard features to do these functions, *Custom Games* added by the user are added to *"%AppData%\Roaming\switchrpcenhanced"* under *"custom-games.json"* and *"discord-assets.json"* respectfully, this is automatically generated when you use it.  You can also use the *Game Box Art Manager* by pressing the *Box Art* button on the display to add images to the correct directory directly from the menu, search for the current status of a game's link to box-art being present, as well as, manually confirm that you've uploaded the image of the box-art to the *[Discord Development Portal](https://discord.com/developers/home)* and add the needed entry to your *"discord-assets.json"* automatically by clicking the *Register Discord Asset* button on the game shown on the menu.

By default it will show the console the title game is played on, as both a large picture and small picture on Discord, including its name and a description message... if a game has had it's image uploaded and linked it will show the large picture as the game box-art and the small picture as the console used.  I've used the Application Name *"Nintendo Switch Status"* due to the console it's for... i.e. Switch, Switch 2, NSO and various retro console options already being shown on the status in an image.

There is also a *favourites section* where your starred games will be displayed, as well as, a *recently played* section to quickly find the games you've actively used.

The search works with game titles and aliases all entered in the database, if you scroll to the bottom of the console sections such as for the *switch* it will also show your *custom games* below the in-built ones, they can also be found directly in the *custom games* section if needed, and searched for in the main search box.

I decided to make it so you don't have close the app to end the status on Discord, I've added a button to *clear activity* which can be used to reset the current selected game and remove it from Discord, while allowing the app to remain open to set a new game if needed.

Oh and you can also hide or show various console sections in the Navigation if you only use *Switch games* and not *Switch 2 games* etc. I think I've covered all the main features...

I feel like I've mentioned everything... I haven't changed anything with the original installation so I'd like to think the installation methods used before will work in this case.

The earlier project this was built from is explained below... all of this still applies really i.e. not directly using an Nintendo API and being a Stand-alone and now more Local method.

### Explanation:

~~SwitchRPCUpdated is the simplest possible~~ An enhanced implementation of Discord Rich Presence for the Nintendo Switch/Switch 2. Instead of directly interfacing with Nintendo's servers like [nxapi](https://github.com/samuelthomas2774/nxapi), ~~SwitchRPCUpdated~~ This allows you to manually set your Rich Presence by setting a game and a description. While not automatic, this method is reliable and is not going to break when Nintendo updates their APIs, unlike nxapi. This project is mainly intended as a backup in case nxapi stops working, but it can also be used in its own right.

### Why a fork?

This fork of the original SwitchRPC was made because it was seemingly abandoned in 2020, leaving only a very small and outdated list of supported titles. The supported title list for the original project was also hosted remotely on the developer's server, making it impossible to update it manually. I would normally be way out of my depth programming something like this from scratch, but fortunately the codebase for SwitchRPC is very small and easy to understand, so I was able to create a fork without much issue. After figuring out how the app worked and how to modify the title list, I decided to make this fork so that the app could be made more useful by adding more titles.

## Installation

Currently available build types:

Windows (Portable), Windows (Installer), Linux (AppImage), macOS (Apple Silicon)

Builds are available in the releases section.

Since I don't have an Intel Mac to build on, macOS x86_64 users will need to build from source.

## Building from source:

### Prerequisites:

Before building, ensure that `nodejs` and `npm` are installed on your device. Instructions for Linux, macOS, and Windows are provided below:
   
   **Linux:**
   
   Arch Linux and related distributions [Manjaro, EndeavourOS] (Pacman): `sudo pacman -S nodejs npm`

   Fedora/RHEL and related distributions [Nobara, Rocky Linux, Alma Linux] (DNF): `sudo dnf module install nodejs`

   Debian and related distributions [Ubuntu, Linux Mint] (APT): `sudo apt install nodejs npm`

   Gentoo Linux (Portage): `emerge nodejs`

   Void Linux (XBPS): `sudo xbps-install nodejs`
   
   **macOS:**
   
   [Brew](https://brew.sh) Package Manager: `brew install node`
   
   **Windows:**
   
   Option 1:
   Instructions to install node.js and npm are provided by Microsoft [here](https://learn.microsoft.com/en-us/windows/dev-environment/javascript/nodejs-on-windows).
   
   Option 2:
   [Chocolatey](https://chocolatey.org/install) Package Manager: `choco install nodejs`
   
Additionally, ensure that `electron-builder` and `@electron/packager` are installed through npm:

   Linux/macOS:
   
   `sudo npm install electron-builder @electron/packager -g`

   Windows:

   `npm install electron-builder @electron/packager -g`

### Building

1. Clone this repository:   
`git clone https://github.com/leonhartm47/SwitchRPCEnhanced.git` 
2. Enter the directory:   
`cd SwitchRPCEnhanced`
5. Install dependencies (if using Windows, you may need to delete package-lock.json):   
`npm install`
6. Build:   
`electron-builder`
7. Done! Your compiled binaries will be in the `dist` folder.
