Manage individual game covers used in the game library. Images are stored in assets/Game Box Arts. Use PNG files named to match the game's expected artwork filename. Console artwork remains in assets/Discord Assets.

Discord Developer Portal image requirements

If you intend to upload a game cover to Discord Developer Portal for use with Rich Presence, your image must be at least 512 × 512 pixels.

We recommend using PNG images that are 512 × 512 pixels or larger. Smaller images may not be accepted by Discord but will be fine locally.
